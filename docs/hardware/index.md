# 硬件组

> 占位。介绍硬件组职责: **PCB 设计 + 模块固件**。
> 区别于电控组(接线、运动控制),硬件组负责电路板级设计、电源管理、以及部分传感器/模块的固件。

## 职责

- 主控板 / 驱动板 PCB 设计
- 电源板设计(Buck、Boost、LDO)
- 传感器模块固件开发
- EMC 与可靠性测试

## 子方向

- [PCB 设计](pcb.md)
- [模块固件](firmware.md)

## 常用工具

- 立创 EDA / Altium Designer
- 万用表、示波器、电子负载
- 烙铁、热风枪
