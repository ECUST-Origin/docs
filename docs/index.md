# ECUST Origin 战队技术 Wiki

欢迎来到 **ECUST Origin** 战队技术文档库。本 Wiki 集中存放 RoboMaster 比赛中各技术方向的设计资料、经验总结与最佳实践。

## 技术组别

本 Wiki 按战队 6 个组别组织文档:

| 组别 | 关注方向 | Wiki 入口 |
| --- | --- | --- |
| 机械 | 底盘、悬挂、发射机构等结构设计 | [mechanical/](mechanical/index.md) |
| 电控 | 接线、运动控制算法 | [embedded/](embedded/index.md) |
| 硬件 | PCB、模块固件 | [hardware/](hardware/index.md) |
| 视觉 | 识别、自瞄 | [vision/](vision/index.md) |
| 导航 | 定位、路径规划 | [navigation/](navigation/index.md) |
| 软件 | 自定义客户端、网站、自制工具 | [software/](software/index.md) |

## 怎么用这个 Wiki

- **新队员**: 先看 [新人入门](getting-started.md),了解每个组别做什么、必备前置知识。
- **正式队员**: 通过左侧目录进入对应组别,查找具体技术细节与设计参考。
- **不确定术语?**: 查阅 [术语表](glossary.md)。
- **外部资源**: 跳转 [资源链接](resources.md)。
