# 软件组

> 占位。介绍软件组职责: **自定义客户端、网站、其他自制工具**。
> 与电控组(下位机 / 嵌入式)区分,本组工作几乎不涉及 MCU。

## 职责

- 自定义遥控器 / 客户端 GUI
- 战队官网 / 招新网站
- 数据可视化与赛后分析工具
- 内部工具脚本(数据处理、对战回放)

## 子方向

- [客户端](client.md)
- [网站](website.md)
- [自制工具](tools.md)

## 常用工具

- C++ / Qt
- TypeScript / React / Vue
- Python 数据处理
- Docker(部署)
