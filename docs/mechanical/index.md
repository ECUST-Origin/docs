# 机械组

> 占位。介绍机械组的职责、设计流程、常用软件、版本管理约定。

## 职责

- 机器人整体结构设计
- 关键受力件校核
- 出图与加工跟进
- 装配工艺与现场问题处理

## 子方向

- [底盘](chassis.md)
- [悬挂](suspension.md)
- [发射机构](launcher.md)

## 设计流程

1. 需求分析(来自战术与规则)
2. 概念设计 + 方案评审
3. 详细设计 + 有限元分析
4. 出图 + 加工单
5. 装配 + 调试迭代

## 常用软件

- SolidWorks / NX / Fusion 360
- ANSYS / HyperWorks(有限元)
- 立创 EDA(PCB 配合)
