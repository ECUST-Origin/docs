# 电控组

> 占位。介绍电控组职责: **接线 + 运动控制算法**。
> 区别于硬件组(PCB、模块固件),电控负责机器人整体的电气连接、传感器数据采集与控制算法实现。

## 职责

- 整车接线与线束设计
- MCU 程序开发(STM32 等)
- 运动控制算法(PID、MPC、状态机)
- 传感器数据融合
- 通信协议实现(CAN、串口)

## 子方向

- [接线规范](wiring.md)
- [运动控制](motion-control.md)

## 常用工具

- Keil MDK / CLion + OpenOCD
